# 外资研报命名：Wiki 兼容口径（2026-09-22）

以用户确认的边界为准，采用 NAMING_RULES_v3_draft.md 的标题、发布日期取值、机构、作者和主题规则。research_meta(2).py 仅为机构名单及抽取算法参考。

- 保留 Wiki 文档 ID、原文版本、页面 slug、SHA-256 去重和解析正文路径。命名结果不是数据库主键，不建立另一套来源索引或去重规则。
- 外资 PDF 文件名采用 `日期_机构_作者ID_主题_代码_英文标题_页数p.pdf`，Wiki 标题采用去掉扩展名的同名标题。原题保留为别名和命名审计信息。旧原件链接保留硬链接兼容。
- 发布日期优先 First Published 的 UTC 日期、首页独立日期、英文标题核对成功后的 Wiki 标题日期，最后仅允许同月且上传前七天内的 PDF 创建日期。上传、入库、文件时间不直接成为发布日期。Wiki 继续保存完整 `YYYY-MM-DD` 日期，不引入 v3 的精度枚举。
- 固定机构字典为附录 A 的 32 家外资券商；境内合资、国内券商及其已列明的香港子公司排除。标题和正文机构冲突留待复核，不自动改判。
- 姓名在固定字典内按机构限定匹配，未匹配才采用有原文证据的姓名。文件中的作者 ID 为小写名加姓，去中间名，保留姓氏连接词。Wiki `authors` 保留规范化姓名，署名顺序、作者 ID 和证据保存在记录的 `naming` 审计中。
- 新增 `topic_primary`，值限定为 v3 的 14 个主题。原 `industries`、`markets`、`subfields`、`research_topics` 保留。不能确定主题时字段为空，标题主题段写 `Unknown`。
- 已核实的机构、作者、日期和主题由管线维护，后续模型抽取不得自动覆盖。通过元数据编辑接口进行的人工修订仍按 Wiki 现有方式操作。
- 国内研报不参与本次命名和字段迁移。关键证据不足、机构冲突或文件名冲突保留原件、进入复核清单。

字典文件：`config/report-dictionaries.json`。机构别名和作者署名证据由已读取的 PDF 初始化；运行时不自动学习或扩充字典。页眉主题优先精确匹配；标题和原有行业用于有记录的次级判断。

历史迁移先运行 `scripts/plan-foreign-naming.mjs` 和 `scripts/migrate-foreign-naming.mjs` 预检，再使用 `--apply`。迁移要求两个后台队列排空并存在本次维护标记，保存 manifest、Wiki 页面、导出记录备份及逐文件操作日志；每份 PDF 改名前校验哈希，不覆盖不同内容。后续新入库由 `applyForeignReportNaming` 自动使用相同规则。
